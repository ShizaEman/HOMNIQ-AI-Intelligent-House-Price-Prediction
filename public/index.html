Architecture Lifecycle

How HOMNIQ AI Works

An automated 5-stage inference cycle connecting your browser directly to the serialized model.

01
Property Features

User specifies 8 physical, dimensional, and qualitative housing attributes.

02
Input Validation

Pydantic strictly enforces ranges, types, and the exact mathematical order.

03
Trained ML Model

Features are fed into house_price_model.pkl loaded in memory via joblib.

04
Price Prediction

Native model.predict() outputs continuous linear valuation estimate.

05
Estimated Value

Formatted price is streamed back to client with interactive visualization.

Data Science Methodology

About the HOMNIQ AI Project

HOMNIQ AI is an end-to-end machine learning system developed to solve the residential property valuation challenge with transparent, explainable AI.

1
Data Preprocessing

Cleaned missing records, imputed architectural attributes, normalized skewness.

2
Exploratory Data Analysis

Analyzed Pearson correlations between property attributes and final SalePrice.

3
Feature Selection

Identified the 8 highest-importance variables maximizing variance explainability.

4
Train-Test Split

Stratified splitting into training and holdout test subsets for honest validation.

5
Model Training

Fitted multiple regression architectures on standardized input vectors.

6
Model Evaluation & Comparison

Benchmarked R², RMSE, and MAE across linear and ensemble candidate algorithms.

7
Final Model Selection

Selected highest-performing model yielding R² = 0.9724 and serialized to pickle.

8
Cloud Deployment

Containerized & serverless FastAPI backend deployed natively on Vercel.
